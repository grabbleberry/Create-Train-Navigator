# Create Transportation

A Minecraft Create Mod addon that adds new features related to trains, such as Third rails, Pantographs, Realistic Steam Engines, Realistic Diesel Engines, Physic Object Straps and Strap Holders (requires Trackwork and Clockwork), Ropes w/ winches, Extended Signals, Rail Bridges (with truss variant, draw bridge variant, suspension bridge variant, and arch bridge variant) in stone, deepslate, and more blocks., and finally fully runnable machines like grinders or redstone on trains.


## 🧩 Dependencies
- This mod requires [Create](https://modrinth.com/mod/create).
- Versions with `C6` are compatible with Create 6, versions without this suffix are compatible with Create 5 (unless Create 6 is the only version available for that Minecraft version)
- Also, if you add Trackwork and Clockwork you can put physics objects on trains.
